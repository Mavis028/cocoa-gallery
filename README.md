# Cocoa Gallery — website

Animated one-page website for **Cocoa Gallery**, handcrafted chocolate bonbons (Egypt).

- Scroll-driven showcase: each bonbon spins in with its own colours and details
- Collection gallery with real product photos
- "Create your own box" builder that sends the order to WhatsApp

## Edit products
Open `index.html` and find `EDIT YOUR PRODUCTS HERE`. Each bonbon has a name, type, description, photo and colours.

## Run locally
Open `index.html` in a browser — no build step.

## Publish with GitHub Pages
Settings → Pages → Source: *Deploy from a branch* → `main` / root.
